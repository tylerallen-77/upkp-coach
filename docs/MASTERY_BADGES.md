# Mastery Badges

Badges are dynamically computed from attempt history and Mastery Challenge sessions.

## Skill gate
A micro-skill gate currently expects:
- >= 5 answered attempts
- recent accuracy >= 82%
- median solve time <= 108% of target
- >= 2 Exam-level (L3+) attempts
- Exam-level accuracy >= 75%
- correct evidence on >= 2 distinct days

## Section challenge unlock
The section needs approximately:
- >= 90% skill coverage
- >= 80% micro-skill gates passed
- sufficient L3+ exposure
- section L3+ accuracy >= 82%

## Mastery Challenge
15 questions:
- primarily Exam L3
- Hard L4 transfer items where supported
- feedback deferred until completion

Pass:
- >= 85% accuracy
- median within 108% of target
- no represented skill below 60%

The challenge does not use Foundation items as the basis for certification.

## Badge lifecycle
Current rebuild:
- In progress
- Challenge unlocked
- Mastered

Future optional state:
- Refresh recommended (badge remains earned, but retention is stale)
