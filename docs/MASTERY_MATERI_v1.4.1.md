# v1.4.1 — Mastery + Materi

## Final mastery seal behavior
- Every badge is always visible.
- Unmastered seals use a muted/grayscale treatment.
- Each seal uses a real semantic SVG icon, never letter initials.
- The outer circular ring represents mastery progress from 0 to 100%.
- At 100%/mastered, the seal switches to a restrained gold treatment with a check marker.
- The same component is reused in Home preview and Progress Mastery Gallery.

## Materi as a first-class learning pillar
Top-level navigation now separates:
- Materi: understand concepts, provenance and freshness, then drill.
- Belajar: adaptive guided practice and direct drills.

Each Materi chapter exposes:
- chapter/subtest
- source/provenance status
- page anchor when available
- verification date when explicitly known
- freshness note
- structured lesson rendering (headings, lists, bold, tables, callouts)
- direct Drill bab ini action

Substansi stays Beta. Material metadata intentionally distinguishes book-anchored, regulation-verified, cross-check-needed and fast-changing content instead of presenting all content as equally authoritative.
