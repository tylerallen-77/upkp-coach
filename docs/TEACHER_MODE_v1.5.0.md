# v1.5.0 — Teacher Mode

Belajar and Materi are redesigned around the behavior of a real teacher rather than a quiz launcher or document library.

## Belajar
- Diagnoses the learner's highest-priority gap from actual attempts.
- Explains why that gap is prioritized.
- Distinguishes misconception, weak concept, speed bottleneck, retention due, and transfer needs.
- Shows the reason behind each step in Today's lesson plan.
- Surfaces a Mistake Clinic from recent error patterns.
- Manual chapter drills show learner-specific evidence and coaching notes.
- Guides the learner to read first when evidence says more question volume would reinforce a misconception.

## Materi
- Uses learner evidence per chapter; reading progress itself is intentionally not gamified.
- Every lesson presents source/freshness, learning objectives derived from the existing material headings, structured content, active-recall prompts, then practice.
- Offers a 5-question warm-up and a 10-question understanding check.
- Substansi source caveats remain explicit.

## During practice
- Every immediate-feedback answer now includes a Coach Note interpreting the error pattern.
- Session completion adds a teacher diagnosis and an explicit next action.

Principle: Teach → Check → Practice → Diagnose → Retry → Master.
