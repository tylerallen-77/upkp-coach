# UPKP Coach v1.4.0 — Visual Soul

This release preserves the v1.3.3 information architecture and adds a professional visual/reward layer.

## Brand
- Native SVG favicon/app icon.
- Navy + gold remain the primary brand.
- Navigation receives compact visual glyphs without increasing menu complexity.

## Mastery
- Ten deterministic vector/CSS mastery seals:
  - TPA: Verbal, Numerical, Logical, Figural
  - Substansi: Etika, Wawasan Kebangsaan, Nilai Kemenkeu, Kepegawaian, Keuangan Negara, Struktur Kemenkeu
- Locked/in-progress/mastered states are visually distinct.
- Mastery progress remains data-driven; visuals do not change mastery rules.

## Home
- UPKP Readiness circular visualization.
- Separate TPA and Substansi completion bars.
- Ten-badge preview.
- Empty session state is visually explicit.

## Progress
- Mastery Room-style gallery.
- Badge progress, Exam accuracy, Exam item evidence and Substansi retention are visible in one card.

## Completion
- Session completion uses a score ring and metric tiles.
- Mastery Challenge success receives a restrained gold treatment.
- No coins, leaderboards, random rewards or forced streak mechanics.

## Motion
- Light hover, button press, progress-fill and seal reveal.
- prefers-reduced-motion is respected.
