# v1.7.0 — Read → Model → Solve → Check

## Reading hints
Every chapter now defines a four-stage reading lens: Scan/Read, Model, Attack/Solve, Check.
Practice sessions expose up to three progressive hints derived from the chapter lens.
Try Out and mastery challenges do not expose hints.
Hint usage is recorded in the attempt payload. Heavy-hint correct answers receive lower adaptive/mastery evidence weight than unassisted answers.

## Tes Potensi formula handbook
The numeric curriculum now has a broad formula handbook covering arithmetic/powers/roots, equations and inequalities, geometry and solids, percentages/social arithmetic, sequences/series, angles and sets, ratio/work rate, distance-speed-time, probability/combinatorics, and statistics/data interpretation.
Formula cards include applicability notes and common traps; they are teaching aids, not a substitute for recognizing the correct model.

## TSKKWK memory bridges
Six learning domains now include mnemonic/memory bridges. Unless explicitly identified as an official acronym (e.g. BerAKHLAK or IProSPeK), the mnemonic is labeled as an UPKP Coach learning aid, not official legal wording.

## Regulation deep dives
TSKKWK lessons add regulation-grounded deep dives tied to the validated current anchors: UU 20/2023; PP 94/2021; PMK 123/2023; PMK 190/PMK.01/2018; the state-finance package (UU 17/2003, UU 1/2004, UU 15/2004); and PMK 124/2024 as amended by PMK 117/2025.

Note: no additional user-supplied PER file was available in the conversation/library at implementation time, so the deep dives are grounded in the validated official regulations already identified, not an unseen document.
