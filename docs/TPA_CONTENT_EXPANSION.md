# TPA Content Expansion

The uploaded UPKP material remains the relevance anchor. External assessment sources are used to expand
construct coverage and archetypes, not to copy proprietary questions.

## External reference families
1. SHL Ability Tests
   https://www.shl.hu/en/tests-tools/ability-tests
   Constructs used: numerical reasoning, deductive reasoning, inductive reasoning, verbal critical reasoning.

2. SHL Practice Tests
   https://www.shlglobal.cn/en/shldirect/en/practice-tests/
   Construct inspiration: statistical/table interpretation and inference.

3. Aon Assessment Practice
   https://www.aon.com/en/capabilities/talent-and-rewards/prepare-for-your-online-assessment
   Construct inspiration: numerical, verbal, inductive and deductive reasoning families.

4. Thomas General Intelligence Assessment
   https://www.thomas.co/assessments/general-intelligence-assessment-gia
   Construct inspiration: reasoning, perceptual speed, number speed/accuracy, word meaning, spatial visualization.

## New/expanded archetypes in this rebuild
- Verbal critical inference
- Constraint ordering
- Multi-step percentages
- Weighted average
- Reverse-percentage transfer
- table/data interpretation emphasis
- pattern decomposition for figural items
- explicit conditional-logic traps

All newly authored Hard items are original templates.

## Content strategy
Question count is not a KPI by itself.
Preferred KPI:
- archetype breadth
- ambiguity-free answer key
- distractor quality
- difficulty separation
- empirical performance stability
- coverage of mastery prerequisites

## Empirical calibration
As multi-user data grows, authored difficulty should be compared with:
- population accuracy
- median solve time
- skip rate
- answer-change rate
- high-confidence-wrong rate

The long-term effective difficulty can combine authored and empirical estimates.
