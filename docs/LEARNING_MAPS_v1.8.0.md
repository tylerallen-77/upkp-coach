# v1.8.0 — Visual Learning Maps

## TSKKWK Knowledge Map
- Six internal learning domains are shown as expandable branches.
- Each branch exposes mnemonic/memory-bridge and concept nodes.
- Clicking a node opens a detail panel with learner evidence, mnemonic/concept detail, reading lens, lesson access and direct drill.
- Node colors/progress reflect learner evidence where available.

## Tes Potensi Formula & Strategy Map
- Top branches follow official user-facing subtests: Verbal, Numerikal, Figural.
- Chapter nodes expose formula count, strategy cards, and current learner evidence.
- Selected nodes reveal formula leaves and a detail panel containing formulas, shortcuts/traps and the reading lens.

## Interaction principles
- Map is an optional visual learning layer; the Course Library and full Lesson pages remain available.
- Desktop uses tree + sticky detail panel.
- Mobile collapses to a vertical expandable tree and non-sticky detail panel; no pinch/zoom dependency.
- No new frontend visualization dependency is introduced, preserving app speed.
